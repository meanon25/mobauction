SkillData.lua contains a numeric subset of the CLASSIC profession table from the locally installed AtlasLootClassic/Data/Profession.lua, extracted on 2026-11-11. Upstream: https://github.com/Hoizame/AtlasLootClassic. The accompanying AtlasLoot GPL v2 license is retained in LICENSE-AtlasLoot.txt. No Auctionator or AHledger source is bundled.

Only recipe spell IDs, minimum skill ranks, profession IDs and output item IDs are included. Blacksmithing and Cooking are selected. This is Classic fallback data, not a verified list of every Forever recipe. The live recipe's profession and output must match before a fallback requirement is used. Reagents and quantities always come from the current game client. Unknown requirements are excluded under an active skill filter. Manually verified requirements can override the fallback.
